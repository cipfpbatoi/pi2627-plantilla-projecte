# Planificació

En el bloc 4 (9 h), la parella planificadora convertix l'avantprojecte rebut en un pla mínim executable. Completeu només el detall que permet iniciar, provar i controlar el recorregut prioritari:

- [`pla-projecte.md`](pla-projecte.md): línia base, EDT, dependències, estimacions, recursos, costos, riscos, execució i control;
- [`pla-proves.md`](pla-proves.md): proves i indicadors traçats als requisits;
- [`pla-desplegament.md`](pla-desplegament.md): entorn, publicació, verificació i recuperació.

Consulteu les [rúbriques del Bloc 4](https://cipfpbatoi.github.io/pi2627/bloc4-rubriques.html): partixen d'estos productes i separen el pla escrit de la defensa i el traspàs individual.

Les issues concretes, fites i tauler es creen en GitHub i s'enllacen des del pla. Quan el professorat accepte el resultat, creeu `traspassos/02-pla-a-prototip.md` a partir de la plantilla d'acta i marqueu la versió `pla-v1.0`.

El pla és acumulatiu: la sessió 1 fixa l'entrada i l'EDT; la sessió 2 ordena, estima i prepara els procediments de control; la sessió 3 concreta el sistema de treball, executa i registra dos publicacions de prova i formalitza el traspàs.
