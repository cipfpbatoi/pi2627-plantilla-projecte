# Avantprojecte

El Dossier 2 es revisa primer sobre un **hash complet de commit candidat**. Després del retorn docent, registreu en l'apartat 14 cada `P` o `N` com una esmena `B3-xx`, amb responsable, data i evidència, i mantingueu una issue `[B3] Tancament del retorn docent de l'avantprojecte` per fer-ne el seguiment.

L'equip marca les esmenes com a preparades per revisar; el professorat les verifica o les accepta com a reserva. Creeu `dossier-2-v1.0` només quan no quede cap `N` bloquejant i la decisió docent siga **apta per planificar** o **apta amb ajustos**.

Conserveu ací el Dossier 2, els models, els diagrames, el prototip de baixa fidelitat i les proves primerenques. En 9 hores, prioritzeu objectius, abast, recorregut principal, dades mínimes, una decisió tècnica justificada i una prova reduïda del risc principal. Enllaceu els fitxers grans o formats externs amb accés verificat i consulteu la [rúbrica publicada del Bloc 3](https://cipfpbatoi.github.io/pi2627/bloc3-rubriques.html).
