Consulteu les [rúbriques del Bloc 5](https://cipfpbatoi.github.io/pi2627/bloc5-rubriques.html): `PR-Q.5.1.x` revisa el seguiment i control documentat en les quatre iteracions, i `PR-Q.5.2.x` la participació, el compliment de condicions i el lliurament final.
